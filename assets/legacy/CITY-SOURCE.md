# Imported ruined-city assets

Author: Majadroid / Maik Hoffmann
Source: https://opengameart.org/content/3d-apocalyptic-building-city-cc0
Download: https://opengameart.org/sites/default/files/lowpoly-apocalyptic-buildings-by-majadroid.zip
License: CC0, confirmed in the source page and the original INFO.txt.

Original files are preserved in apocalyptic-city/LowPoly-Apocalyptic-Buildings-By-Majadroid.
legacy/pybullet/tools/prepare_city_assets.py converts the seven supplied FBX buildings and the wreckage set to Z-up OBJ geometry, retains original texture coordinates, and scales each horizontal footprint to 4.1 m. Static concave triangle collision meshes match the converted visuals. Texture photographs come from the original asset archive. legacy/pybullet/city_map.py places these prebuilt models into the local earthquake district. The district layout and rescue tasks are local additions; this is not the author's original Blender scene or a complete third-party disaster simulator.
